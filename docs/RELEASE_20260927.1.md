# iOS 1.0 / 20260927.1 — source release, 2026-09-27

This GitHub release publishes the current survey-only source snapshot, not a publicly installable IPA.
Install through the existing [TestFlight entry](https://testflight.apple.com/join/br5vTV92); available builds and capacity are controlled by Apple. **This GitHub release does not upload or approve a new TestFlight build.**

## Changes / 更新

- Disable extra phone-side survey-frame archives by default. Explicit live cloud upload still prepares temporary frames and cleans them up after queue handoff/rejection.
- Treat unverified/mismatched camera geometry as an advisory instead of blocking otherwise available capture/control. Preserve camera readiness checks.
- Stop-and-capture pose checks apply to point captures, not ordinary interval-strip starts.
- Preserve prior successful camera parameter readback when a later request fails; existing freshness checks still apply.
- Add phone-retention and survey regression coverage and synchronize Chinese/English cloud, camera and simulator FAQs.
- 默认不额外存手机图传图片，保留主动云端上传及必要缓存；相机参数提示不再直接阻断航线；普通航带不套用停点拍照要求。

## Distribution and limits

- Release simulator tests: **196 passed, 2 skipped, 0 failed** (198 total).
- Generic iOS device Release archive succeeded with signing disabled; retained locally for build verification, not offered as a phone installer.
- GitHub provides source archives and notices. Local unsigned device archives and simulator products are not iPhone installation packages and are not attached as an IPA.
- Release disables terrain following and private model inference. SDK/application keys and signing credentials are not in this source release.
- Reference aircraft is Mini 2 with MSDK 4.16.2; this is not an iOS MSDK V5 client.
- Automated build/tests do not establish real-flight safety. Confirm actual captured indicators and aircraft files, rehearse the route, and retain pilot supervision.
