# iOS 图片上传与云端重建

适用于包含本功能的源码构建；旧安装包 / 旧 TestFlight 不会自动更新。私有版和开源版
使用相同协议，不需要手机端模型。工作站部署统一见 OpenFlyScan 的 `docs/workstation.md`。

## 创建会话

1. “区域航线 → 云朵 / 更多 → 云端点云与航线”，展开图片上传区。
2. 填手机可达的 HTTP/HTTPS **服务根地址**和访问码，不是 SSH 地址；手机上的
   `127.0.0.1` 指手机自己。优先 HTTPS，开源版没有私有公网 HTTP 白名单。
3. 填名称、**对应上传图片的水平 FOV**、最短拍照间隔和可选的起飞点绝对海拔 ASL。
   已确认相机的参数仅用于预填，仍需核对视频裁切 / 原片模式；不是标定内参。
4. 点击“创建上传会话”并保存会话 ID。队列固定绑定服务器和相机 / 高度配置，
   修改只读浏览器地址不会转发队列。换相机或起飞基准应另建会话。

iOS 声明支持 schema 13 / 14，默认请求停车拍照；勾选“连续补拍（实验）”才请求
schema 14 的 `CONTINUOUS_EXPERIMENTAL`。已有会话不会因修改选项而被改写。未填起飞 ASL 仍可
重建 / 看点云，但工作站不导出飞行航线。**相对飞行高度不能当作 ASL。**

## 图片来源

**实时采集**：开启后上传此后航线拍照触发后的新图传帧，不是持续录像、手动快门监听，
也不是机载 SD 原片。保持实际图传宽高比，最长边不超过 1920，不复用模型拉伸图。
网络不阻塞航线控制。需要新鲜飞控时间、有效 GPS / ASL；有新鲜实际云台姿态时附带姿态，
不编造坐标。HIL / DJI 仿真 / Mock 帧不混入真实会话。未入队原始记录可能仍在航线日志中，
页面显示拒绝数量，不能将其视为已上传。

**历史照片**：从“文件”或“相册”选择 JPEG / PNG，每批最多 100 张。读取原图 EXIF
GPS 经纬度和绝对海拔，不套用当前手机 / 飞机位置。无定位或海拔的图片会拒绝；
HEIC 需先导出保留元数据的 JPEG。不重压缩原片。先关闭实时采集再导入历史照片；
执行 / 暂停航线时禁用历史选择，实时采集与历史导入不并行。

每张限制 48 MiB / 6000 万像素。队列最多 1000 张，待传副本合计不超过 512 MiB。
不同图片几何、FOV 或起飞基准不要混入同一会话。

## 队列、重试与提交

- 先复制入独立磁盘队列，串行 PUT；服务器确认后才删队列副本，原片和原始日志不删除。
  重试使用同一序号；客户端不额外做全文件哈希，服务端可返回重复图片确认。
- 暂时断网 / 408 / 429 / 5xx 最多自动重试两次，然后暂停并保留文件。401 / 403
  应更新绑定会话的访问码；恢复上传需要手动操作。
- 关闭面板不销毁队列；进入后台暂停上传和实时采集。重启 App 恢复为**暂停队列**，
  核对会话后“继续上传”，不是后台无限上传服务。
- 关闭实时采集，等导入和全部待传图片成功上传，再点“结束上传并提交重建”。
  **不会自动 finalize**；被拒绝图片不计入待传，提交前检查拒绝记录。提交后不能追加。
- 可刷新状态、重试已提交重建，点击“读取此会话结果”进入
  [点云与航线流程](CLOUD_ROUTE_WORKFLOW.md)。结果仍需手动读取 / 刷新。
- “取消服务器任务”保留本地副本；“清理本地队列”删除待传副本但不删远端数据。
  均有确认，清理前保存会话 ID。损坏队列不自动覆盖，提供显式清理恢复入口。
- 访问码存入按服务来源隔离的本机 Keychain，不写入队列清单、航线或日志。

## 飞行与验证边界

已有会话浏览器仍是只读下载入口，上传区才创建 / 提交 / 取消服务任务。上传或导入
不申请控制、不起飞、不自动执行。服务当前输出 `safe_to_execute=false` /
`flight_authorized=false`，不构成飞行授权；仍需审核及原有相机、坐标、高度、本地预检。
图传与原片几何不同也可能导致相机校验拒绝，不改字段绕过检查。

自动测试使用模拟 HTTP 和本地图片，覆盖协议、队列、恢复、失败保留及显式提交；
不能代替真实 iPhone 相册权限 / DJI 采集、工作站 GPU 重建和最终补拍飞行验收。
